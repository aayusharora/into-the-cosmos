Thirty seconds, and the docstring is the whole slide. Notice what it says: call this FIRST. That's not documentation, it's instruction, and it's the only way the model knows the order to do things in. Then the distinction, which is worth being precise about because people conflate them. previous_interaction_id keeps tonight's conversation together: what you said two messages ago. It does nothing for next week. Facts that outlive the conversation need somewhere to sit, and in my case that's a JSON file with three keys in it. Turn the page and show them the difference it makes.
