Gemini never calls your function. Not once. Not ever. It has no network connection. It does not have your API key. It cannot run your Python. It says a name and waits. If you do not run it, nothing happens. The agent just stops, politely, mid thought. Half the tutorials online draw this arrow. Model straight to API. That arrow does not exist, and it is the single biggest reason people get stuck on day one. Only one box here has legs, and it is yours.
