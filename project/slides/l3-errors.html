space_weather: AttributeError: 'dict' object has no attribute 'index'

My bug, first run. NOAA returns a list of dicts, not rows. The model can’t do a thing with that sentence.

return {"error": "space weather unavailable",

        "can_continue": True}

Now it answers with three tools and tells you one is missing. Your error messages are prompts now.

This is a real traceback from the first time I ran the four tools. NOAA changed shape on me. I expected rows with a header, it sends a list of dictionaries. Read it out and then ask: what is a language model supposed to do with that? It's a sentence about Python internals. It can't fix my parser and it can't tell the user anything useful. The fix isn't to hide the failure. It's to say what failed, in words aimed at the reader, who is now a model, and whether the rest of the job can go on. Then it answers with three tools instead of four and tells the user the aurora check was unavailable. That's a good night's work, not a crash. The sentence to leave them with: once you hand tools to a model, your error strings stopped being for you.
