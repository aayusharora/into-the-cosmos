Same endpoint as the planets, different body code.

Twenty seconds. The Moon is the thing nobody thinks of and it ruins more observing nights than cloud does. A full Moon above the horizon washes out everything faint. You can still see planets, but nothing else. Note the second half of the docstring, because that's the part doing the work: if it rises late, the early night is the good part. That sentence is what lets the model say "go now" instead of just reporting a time. Same JPL endpoint as the planets, body code 301.
