Lesson 6 · the one that matters

I thought all four tools worked

✓ sky_conditions

✓ planets_tonight

✓ moon_tonight

✗ space_weather

 

3/4 tools working

First run this morning. I’d have sworn it was four.

Nothing crashed. It would just have quietly stopped mentioning the aurora.

One command, no API key, four seconds:

tonight.py --tools-only

Agents fail quietly. If you’re not counting, you’re guessing.

This is the lesson I'd protect over every other one, and today it caught me. I wrote four tools. I was certain all four worked. I ran the check and three did. NOAA had changed the shape of its response and my parser was wrong. Now notice what would have happened without the check. Nothing visible. No crash, no red text. The agent would have answered the question perfectly well using three tools and quietly stopped ever mentioning the aurora. I'd have demoed that on this stage and never known. That's how agents fail. Not loudly. They just get a bit less useful, and nobody notices for a month. The habit: a command that exercises every tool, with no model and no key, that you run after every change. Mine takes four seconds. Then the bigger version, if you've time: the real score is whether the answer was right, and for that you need ground truth you held back. Everyone in this room has some: closed tickets, last quarter's forecasts. You already know how all of it turned out.
