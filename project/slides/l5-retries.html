Retry inside the tool

for n in range(3):

    except Exception: time.sleep(1.5 * (n + 1))

JPL and NOAA both drop requests that work a second later.

So does the model. gemini-3.8-flash gave me 503, repeatedly, building this talk.

Never make a model reason about HTTP. It apologises instead of retrying.

Three lines, and they're the difference between a demo that works and one that works on stage. Every one of these endpoints is free and public and occasionally drops a request that succeeds a second later. If that failure reaches the model, it does the polite human thing. It tells the user it couldn't check, and gives up. It won't retry, because nothing told it to. Then the honest confession, and it's a good one: the model did this to me too. The free tier of gemini-3.8-flash returned 503 over and over while I was building this, and then stopped answering altogether, which is why some of tonight is recorded rather than live. So the retry belongs one layer down, in the tool, where it's three lines and nobody has to think about it.
